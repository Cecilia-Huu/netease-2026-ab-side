# 网易云音乐 2026「我的 AB 面」H5 原型

本项目是用于内部评审的高保真交互 Demo，数据和艺人内容均为模拟占位，不连接真实网易云音乐接口。

线上演示：<https://cecilia-huu.github.io/netease-2026-ab-side/>

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

开发服务器运行时可批量导出 12 张 390 × 844 的独立页面截图：

```bash
npm run screenshots
```

桌面端提供演示导航；手机端仅显示 390px 优先适配的活动页面。推荐在 Chrome DevTools 中使用 390 × 844 视口体验。
